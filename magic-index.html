Import Excel

Select one or more report files. The selected files are listed below — press OK to import them all. Reads the sheet that is OPEN in Excel (the active sheet). The header row must have the column names (Merchandiser, Buyer, PO, Style...). If PO + Style match, the old row is UPDATED; if not, a NEW row is added. No old row is ever DELETED — the new styles are added to the list together with the previous styles. On update, the old value is saved in History with the date.

Users & Groups (Admin)

How to set up a group — 3 steps:
  1. Create a group — type a group name, tick its buyers, press Create group.
  2. Select the group — in the Groups list, press Manage on that group.
  3. Add members — tick the users who belong to this group, press Save group. All members see the group's buyers.
